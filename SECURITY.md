# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub Private Vulnerability Reporting:
[open a report](https://github.com/castrowithcee/qatlas-crew/security/advisories/new). Do not open a public
issue or pull request for a vulnerability.

A report should name the affected version, the impact, and the steps or input that reproduce it. The fix is
published as a new release together with a security advisory.

## Supported versions

Only the latest release receives security fixes. Before `v1.0.0`, fixes are not backported to earlier
minor releases.
